# HSD/runtime: original main heap — 2026-10-03

The runnable XEX now executes the original HSD_CreateMainHeap lifecycle during boot, before any HSD assets are allocated. It calls the unchanged HSD_ObjInit and original forget callbacks, destroys and recreates the OS heap, selects it and updates the object allocation budget. Original pool initializer/getter/forget bodies from aobj, robj, mtx, shadow, tev and displayfunc are compiled as extracted C modules. There are no replacement stubs.

The heap identifiers and arena bounds are shared with the existing native owner-aware allocator. A precondition rejects resets while either HSD allocations or raw OS allocations are live. It also rejects misaligned, reversed, undersized or out-of-owned-arena bounds. This deliberately restricts use to empty-heap boot/reset; transitions that discard occupied original heaps are not implemented safely yet. The original forget callbacks cannot discover port-owned asset pointers. The ownership table remains valid when the OS heap handle is reused.

Files: `src/hsd_memory.c`, `src/hsd_main_heap_original.inc`, six `src/hsd_pool_*.c`, `diagnostics/generate_hsd_runtime_pools.py`, `src/main.cpp`, project and verifier. Pool bodies are unchanged; original static pool state is promoted to shared linkage only where needed by the audit remainder. Generated remainder modules retain all other original functions and reference exactly that same state. The audit therefore avoids duplicate implementations or disconnected pool copies. The original decomp checkout has no changes.

Full-module compilation first exposed 10 missing initialization functions, C syntax/header incompatibilities and then 56 unrelated drawing dependencies. The final runtime compiles only the real needed original pool bodies, while the audit still includes original remainders. Existing math boundary declarations and LINT are used for these C fragments; LINT disables original compiler layout assertions, so this is not a claim that every imported structure ABI has been validated. Original display-list/Z-list structs and initializer sizes remain intact. The complete HSD render modules are not present in the production image.
