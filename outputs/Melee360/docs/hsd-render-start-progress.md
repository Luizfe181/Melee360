# Original HSD render start — 2026-10-03

The runnable XEX now supplies the original HSD_GetCurrentRenderPass, HSD_StartRender and HSD_Init_803755A8 bodies from initialize.c unchanged. Native bootstrap obtains the actual D3D render target dimensions, initializes the original HSD_VIData/current render-mode structure with a progressive, non-AA framebuffer descriptor, and selects RGB8/Z24. HSD_VIGetRenderMode is the original inline getter. Before each normal frame is drawn, the loop calls the original HSD_StartRender(HSD_RP_SCREEN).

GXSetFieldMode is a constrained native implementation: the supported progressive/non-half-aspect mode restores full native pixel/sample coverage (XDK MULTISAMPLEMASK has 16 effective bits). Interlaced fields or half-height line/point footprints are rejected. This is not complete GX field rendering. The first probe mistakenly expected 32 mask bits on readback, failed, and was corrected to the native 16-bit mask. Successful GPU cases and subsequent presentations verify the final image; failed candidates were never published.

Boot tests deliberately switch to depth-only writes and zero coverage, then call original HSD_StartRender for each of SCREEN, TOPHALF, BOTTOMHALF and OFFSCREEN. They verify pass state, RGB write mask restoration, full sample mask and the original post-render helper behavior. Passing those enum values tests state/lifecycle only: it does not mean split-screen half-pass rasterization or offscreen target allocation was implemented. HSD_Init_803755A8 is intentionally a no-effect original matching artifact (comparison rather than assignment), not a fabricated missing-function stub.
